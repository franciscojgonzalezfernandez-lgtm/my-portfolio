🚀 About This Project
A state-of-the-art portfolio built with the absolute latest in frontend technology – showcasing Next.js 16, React 19 (with its revolutionary new compiler and garbage collector), Zustand for lightning-fast state management, and designed with V0's AI-powered UI generation.

This isn't just a portfolio – it's a live demonstration of modern frontend engineering at its finest: zero-config SSR/ISR, bleeding-edge React patterns, and pixel-perfect design that scales effortlessly.

🔥 Getting Started
bash

# Clone the repo

git clone https://github.com/franciscojgonzalezfernandez-lgtm/my-portfolio.git

# Install dependencies

npm install

# Run dev server

npm run dev

# Build for production

npm run build

# Deploy to Vercel (one command!)

npm run deploy
