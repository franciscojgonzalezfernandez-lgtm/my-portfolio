# Javi's Portfolio - Cutting-Edge Frontend Showcase

## 🚀 About This Project

**A state-of-the-art portfolio** built with the absolute latest in frontend technology:

- Next.js 16 (App Router, Turbopack, Server Actions)
- React 19 (new compiler, garbage collector, Server Components)
- Zustand (lightning-fast state management)
- V0 AI design + TailwindCSS
- TanStack Query for data mastery
- Shad/cn on top of Radix UI for an optimized Accesibility

**[Live Demo](https://franciscojgonzalezfernandez-lgtm.github.io/my-portfolio/)**

## ✨ Featured Technologies

| Category   | Tech Stack                            |
| ---------- | ------------------------------------- |
| Framework  | Next.js 16                            |
| Library    | React 19                              |
| UI         | **Shadcn/UI** (perfect accessibility) |
| Primitives | Radix UI                              |

| Design     | V0 + Tailwind                         |

## 🎯 Getting Started

```bash
git clone https://github.com/franciscojgonzalezfernandez-lgtm/my-portfolio.git
npm install
npm run dev

```
